
# 🪄 拉比的文字魔法 for 卿卿我我
> **輕鬆轉換文字格式｜AI 聊天紀錄小說體化與潤飾工具**

替換文字全半形、手動替換一絲等詞的網頁小工具，可全部搜尋指定詞並自由勾選哪個要替換。
可自由地調整四個區塊位置放大縮小
---

## ✨ 優點

- **🔒 100% 本地安全運作**：所有文字處理均在你的瀏覽器內完成，不會上傳或留存任何對話資料，重新整理（F5）即清空內文。
- **📖 一鍵小說體化**：清理對話 APP 格式，將聊天紀錄排版融合成順暢的小說內文，並原汁原味保留敘述與段落結構。
- **🔍 互動式搜尋與逐筆取代**：類似 `Ctrl + H` 功能，自動高亮目標並提供前後文對比，可自由勾選項目或針對單一筆進行個性化修改。
- **🎨 自由拖移與縮放介面**：所有視窗（原始內文、變更結果、魔法箱、字典）皆可自由拖移位置，並支援 `🔍＋` / `🔍－` 微調視窗大小。
- **📚 個人化魔法字典**：內建高頻 AI 詞彙，並支援建立個人專屬的尋找/取代/繁簡對應詞庫（自動儲存於本地瀏覽器）。

---

## 📖 使用指南

### 1. 快速整理：小說體化功能

將聊天對話一鍵轉換為小說排版：

1. **匯入文本**：在【📝 原始內文】點擊 **📋 貼上內文**（自動讀取剪貼簿）、直接手動貼上，或點擊右上角 **📂 上傳 .txt**。
2. **自訂去除選項**（點擊 📖 按鈕旁 ⚙️ 齒輪）：
   - ☑ **去除時間戳記**：刪除 `[YYYY-MM-DD HH:MM:SS]`。
   - ☑ **去除說話者名字**：刪除 `名字:` 或 `名字：` 前綴。
   - ☑ **去除 `*動作*` 標記**：剝除最外圍的星號/括號，保留內部的敘述文字與換行。
   *(選項皆可獨立勾選，設定會自動儲存於瀏覽器！)*
3. **執行轉換**：點擊 **📖 小說體化**，即可在【✨ 變更後結果】預覽成果。

---

### 2. 精準搜尋與批次 / 個別取代

針對 AI 常見詞（如：「一絲」、「甜美」）或漫山遍野的「……」進行替換：

1. **開啟魔法箱**：按 `Ctrl + H` 或點擊【🧰 拉比的魔法箱】。
2. **輸入與對比**：輸入「尋找目標」與「預設取代為」，下方清單會自動列出所有找到的項目，並顯示前後約 25 字的上下文對比。
3. **彈性勾選與單獨修改**：
   - 透過勾選框，自由決定哪些項目要替換、哪些要保留。
   - **個別指定**：可在單一項目右側文字框輸入不同的替代詞（例如：項目 1 改成「A」、項目 2 改成「B」）。
4. **執行替換**：確認無誤後點擊綠色按鈕 **【執行選取取代】**。
5. **輸出結果**：在【✨ 變更後結果】確認最終成果，點擊 **💾 下載 .txt** 或 **複製結果** 即可！

---

### 3. 快捷排版與魔法字典

#### 🛠️ 一鍵工具列

- **轉為全形 (半形 → 全形)**：將半形標點符號轉換為全形（智慧避開英數字、星號 `*`、等號 `=`、括號與時間格式，並自動修復刪節號 `……`）。
- **繁體 > 簡体 / 簡体 > 繁體**：進行繁簡體轉換，支援使用【📝 自訂繁簡詞】建立專屬對應詞庫（避開專有名詞單字誤換）。
- **重置為原始內文 / 清空取代內文**：方便隨時還原重新操作。

#### 📚 魔法箱的字典

- **預設詞庫**：點擊字典內的預設詞彙（如：`……`、`一絲`、`「」`）可直接快速帶入搜尋與取代框。
- **替換語句（⚙️）**：點擊【📌 尋找詞彙】右上角齒輪可展開「常態長句/套路」面板。
- **自訂詞庫**：支援自由新增與刪除個人常用詞彙（點擊 `🗑️ 清空自訂` 可一次抹除自訂項目）。
