使用說明：
１、貼上文字後，在魔法箱填上你想取代的詞。一填入，魔法箱的搜尋區塊會自動帶入找到的文字跟前後文約十五字
２、多選項打勾可自由決定是否全數替換內文，允許項目１改成Ａ、項目２改成Ｂ
３、輸入你想改的文字後，點綠色按鍵【執行選取取代】
４、查看藍線的視窗【變更後結果】

💡 視窗與介面操作

    自由拖移與縮放：所有視窗（原始內文、變更結果、魔法箱、詞庫）皆可按住頂部欄位自由拖移位置。
    點擊頂部的 🔍＋ 與 🔍－ 可任意放大或縮小視窗。

    快捷鍵隱藏/顯示：

        Ctrl + H：顯示 / 隱藏【🔍 拉比的魔法箱】

        Ctrl + T：顯示 / 隱藏【🔤 自訂繁簡詞庫】

📖 一、快速整理：小說體化功能

將對話紀錄一鍵轉換為順暢的小說內文排版：

    載入文本：在【📝 原始內文】貼上文字，或點擊右上角 📂 上傳 .txt。

    自訂去除選項（點擊 ⚙️ 齒輪）：

        ☑ 去除時間戳記：刪除 [YYYY-MM-DD HH:MM:SS]。

        ☑ 去除說話者名字：刪除 名字: 前綴。

        ☑ 去除 *動作* 標記：剝除最外圍的星號，保留裡面的敘述。
        (三個選項皆可獨立運作、自由搭配，設定會自動儲存！)

    執行轉換：點擊 📖 小說體化，即可在【✨ 變更後結果】查看成果。

🔍 二、精準搜尋與批次/個別取代

處理 AI 常用詞（如：「一絲」、「意味」）或漫山遍野的「……」：

    輸入與對比：在【拉比的魔法箱】輸入「尋找目標」與「預設取代為」。
    下方清單會自動列出所有找到的項目，並顯示前後約 25 字的上下文對比。

    彈性勾選與單獨修改：

        可透過勾選框，自由決定哪些項目要替換、哪些要保留。

        個別指定：可以在單一項目的右側文字框輸入不同的替代詞（例如：項目 1 改成「A」、項目 2 改成「B」）。

    執行替換：確認無誤後，點擊綠色按鈕 【執行選取取代】。

    檢查與輸出：在【✨ 變更後結果】確認最終成果，點擊 💾 下載 .txt 或 複製結果 即可帶走！

📚 三、快捷排版與魔法字典

    一鍵轉換工具：

        轉為全形：將半形標點符號轉換為全形（自動避開星號 * 與時間戳記）。

        繁體 > 簡体 / 簡体 > 繁體：進行繁簡體轉換，支援使用【📝 自訂繁簡詞】建立專屬對應詞庫（避開單字誤換）。

        重置為原始內文 / 清空取代內文：方便隨時還原重新操作。

    魔法箱的字典：

        點擊字典內的預設詞彙（如：……、一絲、「」）可直接快速帶入搜尋與取代框。

        支援在【自訂詞庫】新增或刪除個人常用的詞彙。
